# Bike Sharing: pronóstico de demanda

Pronóstico de la demanda de bicicletas compartidas de Capital Bikeshare (Washington D.C., 2011–2012) con modelos estadísticos y de machine learning, comparados por horizonte de pronóstico.

> Proyecto en construcción.

## Instalación

Requiere Python 3.13.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Pruebas

```bash
pytest
```
